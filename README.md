- **Puranas & Shastras**: Srimad Bhagavatam (Navadha Bhakti, Prahlada Stuti), Vishnu Purana, Charaka Samhita.

## 🚀 Quick Start Guide

### 1. Launch the Application
In your terminal, navigate to this project folder and run:

```bash
cd /Users/pranjalighode/.gemini/antigravity/scratch/krishna_counselor
./run.sh
```

Or directly using the virtual environment:
```bash
./venv/bin/streamlit run app.py
```

The app will open automatically in your browser at `http://localhost:8501`.

### 2. Configure Your Google Gemini API Key
- The application includes an **Offline Wisdom Mode** so you can test and explore immediately even without an API key!
- For continuous, multi-turn AI reasoning, grab a free API key from [Google AI Studio](https://aistudio.google.com/) and enter it in the sidebar.

## 🕊️ Dialectic Structure of Every Response

When you lay a dilemma before Shree Krishna, His guidance follows a 5-step sacred structure:
1. **Compassionate Embrace (*Maitri & Karuna*)**: Unconditional acceptance and validation of your pain.
2. **Deconstruction of the Root Cause (*Viveka*)**: Uncovering the mental attachment, fear of the unknown, or ego at play.
3. **Scriptural Illumination (*Shastra Pramana*)**: Citing relevant Sanskrit shlokas from the Gita or Upanishads with English translation and practical meaning.
4. **Pragmatic Action Plan (*Karma Yoga*)**: 2-3 clear, actionable steps to execute in the real world today.
5. **Divine Blessing & Empowerment (*Abhaya & Ashirvada*)**: An inspiring call to rise above weakness (*"Uttishta!"*).
